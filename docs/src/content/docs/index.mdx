## What's included

<CardGrid>
  <Card title="Authentication" icon="seti:lock">
    Stateless JWT with Bearer header or HttpOnly cookie, remember-me, refresh, and real logout through a
    Redis token denylist.
  </Card>
  <Card title="Account flows" icon="email">
    Email verification and password reset with single-use, hashed, expiring tokens. Mailpit catches mail in
    development.
  </Card>
  <Card title="Abuse protection" icon="warning">
    Login lockout per IP and account, plus a per-IP API rate limit, shared across instances through Redis.
  </Card>
  <Card title="Standard HTTP" icon="seti:json">
    Versioned `/api/v1` URLs, correct status codes and RFC 9457 problem details for every error.
  </Card>
  <Card title="Observability" icon="seti:graphql">
    Prometheus metrics, OpenTelemetry tracing, trace ids in logs and the `X-Trace-Id` header, JSON logs in prod.
  </Card>
  <Card title="Quality gates" icon="approve-check">
    Testcontainers, ArchUnit and k6 tests, Trivy image scan, Dependabot, strict Doxygen documentation.
  </Card>
</CardGrid>
